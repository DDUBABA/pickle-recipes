1. 서비스와 이용 동의

Pickle Recipes(피클 레시피)는 피클 제작사와 무관하게 운영되는 비공식 서드파티 커뮤니티입니다. 제작사의 공식 서비스·제휴 서비스가 아니며, 게시물에 대한 제작사의 검토·보증을 의미하지 않습니다. 운영자는 jkc1832입니다. 이 약관은 본 커뮤니티의 자료 검색·배포·기여 접수에만 적용되며, 피클 제작사의 약관이 아닙니다. 피클이라는 이름은 자료의 활용 대상을 설명하기 위해 사용합니다. 사용자의 AI, 외부 서비스, 로그인 브릿지는 각각 별도의 시스템입니다.

이 사이트의 검색·설치·실행·업로드 연동을 이용하려면 이용약관, 면책, MIT 라이선스 및 아래 기록 수집에 명시적으로 동의해야 합니다. 피클은 사용자에게 전문 링크가 포함된 버튼 카드를 제시해야 하며 동의를 대신 선택할 수 없습니다. 동의하지 않으면 이 사이트와의 연동을 중단합니다. 가이드와 약관 등 공개 안내 문서는 동의 전에 볼 수 있습니다.

매 이용 시 최신 약관 버전을 확인합니다. 버전이 변경되면 즉시 중단하고 새 버튼 카드로 재동의를 받아 서버에 기록한 뒤 진행합니다. 동의 토큰은 사용자 측에 안전하게 보관하며 공개하지 않습니다.

2. 자동화와 면책

공유 코드는 현재 상태로 제공됩니다. 정확성·지속적 동작·목적 적합성이나 외부 서비스와의 호환성을 보장하지 않습니다. 외부 API 변경, 서비스 중단, AI 판단 오류, 사용자 설정에 따라 잘못된 실행이 발생할 수 있습니다. 법률상 배제할 수 없는 책임은 배제하지 않습니다.

사용자는 실행 전 대상·권한·비용·영향을 확인해야 하며, 결제·삭제·전송 등 중요한 동작에는 별도의 실행 승인을 적용해야 합니다. 제3자 서비스의 약관과 접근 정책을 준수하고 권한이 없는 시스템에 접근하지 않아야 합니다. 보안 스캔은 위험을 줄이지만 안전성을 보증하지 않으며, 접수 PR은 운영자 검토 후 병합합니다.

3. MIT 공개 라이선스와 기여

공유 코드와 문서는 MIT 라이선스 전문에 따라 공개됩니다. 저작권 및 허가 고지를 유지해야 합니다. 업로더는 해당 자료를 공개할 권한이 있어야 하며 제3자의 비밀·권리·개인정보를 포함해서는 안 됩니다.

자동 업로드는 별도의 선택 동의입니다. 이 사이트의 제출 규격에 맞춘 생성과 개인정보 제거 검증을 마친 공통 코드만 PR로 제출하는 것을 허용합니다. 선택하지 않아도 검색과 다운로드를 이용할 수 있습니다. 자동 업로드 동의가 없으면 업로드하지 않습니다.

PR 번호가 접수번호이며 병합은 보장되지 않습니다. 버전과 릴리즈 이력은 서버 자동화가 확정합니다. 요청자의 공개 별칭, 기준 버전, 동의 ID, 약관 버전, 요약 및 코드가 GitHub 공개 PR에 기록됩니다. 비밀 동의 토큰, 개인 식별자 원문, IP 주소와 사용자 에이전트는 PR에 게시하지 않습니다. 공개 기여는 복제·포크될 수 있어 완전한 회수가 불가능할 수 있습니다.

4. 동의·다운로드 기록 수집

필수 수집 항목은 사용자 식별자(피클 핸들 또는 임의 식별자), 접속 IP, User-Agent, 클라이언트 종류, 동의 시각·약관 버전·동의 ID, 다운로드 항목·종류·버전·시각입니다. 표시 이름은 선택입니다. 실명·전화번호·이메일 대신 임의 식별자를 사용하세요.

목적은 약관 동의 증빙, 다운로드 집계, 서비스 운영 및 오남용 확인입니다. 기록은 Cloudflare D1에 보관하고 관리자만 사용자별 통계를 조회합니다. 항목별 다운로드 횟수는 서비스에 표시됩니다. 계정 비밀번호, 서비스 인증키, 개인 프로필 파일은 이 사이트에 보내지 않습니다.

기록은 위 목적이 유지되는 동안 보관하고 목적 소멸 또는 유효한 삭제 요청 처리 시 삭제하거나 비식별화합니다. 공개 PR의 기여 이력은 GitHub와 복제본에 남을 수 있습니다. Cloudflare 및 GitHub의 인프라 처리 위치와 정책이 적용될 수 있습니다.

동의를 거부할 수 있으나 필수 동의 없이는 연동 서비스를 이용할 수 없습니다. 브라우저의 ‘이용 동의 정보 지우기’는 로컬 동의 자격정보를 지우고 연동을 중단하며, 기존 서버 기록 삭제를 의미하지 않습니다. 기록 열람·삭제·정정 요청은 운영 저장소 문의로 비공개 연락 경로를 요청하세요. 공개 이슈에는 개인 식별자나 동의 토큰을 작성하지 마세요.

5. 사용자 설정 보존

공유 파일에는 공통 코드만 포함합니다. 연동 도구는 이 커뮤니티의 저장 규칙에 따라 비비밀 개인정보를 사용자 측 ~/.config/pickle-profile/profile.json에서 우선 참조해야 합니다. 인증 정보는 사용 환경에서 지원하는 보안 보관소 또는 로그인 브릿지로 관리해야 합니다. 업데이트 시 개인 설정과 예약 폴더를 보존해야 합니다. 이 경로와 연동 규칙은 이 사이트가 정한 것이며 제작사의 공식 저장 규격을 뜻하지 않습니다.
