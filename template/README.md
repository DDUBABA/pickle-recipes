# 커넥터 또는 레시피 이름

## 개요
이 파일은 피클 제작사와 무관한 비공식 Pickle Recipes 커뮤니티의 제출 양식입니다. 제작사의 공식 SDK나 템플릿이 아닙니다.
서비스와 수행하는 작업을 설명하세요.

## 필요한 커넥터
커넥터는 없음. 레시피는 requires에 지정한 커넥터와 실행 순서를 설명하세요.

## 설정
비비밀 개인정보는 사용자 측 ~/.config/pickle-profile/profile.json을 먼저 참조합니다.
위 경로는 이 커뮤니티의 저장 규칙이며 제작사의 공식 규격이 아닙니다. 인증키는 사용하는 AI 환경의 보안 보관소에서만 가져옵니다. 공유 파일에 실제 값을 쓰지 않습니다.

## 실행
python scripts/service_template.py --json
이 사이트 자료의 실행 직전 커뮤니티의 최신 약관 동의를 검증하세요. 이 템플릿은 실제 서비스 동작을 구현하지 않습니다.

## 개인정보 보호
개인 프로필과 인증 정보를 서버나 공유 파일에 넣지 않습니다. 업데이트는 공통 코드만 교체합니다.

## 변경 이력
버전과 릴리즈 노트는 병합 시 자동 확정됩니다.
